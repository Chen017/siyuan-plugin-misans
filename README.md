## About MiSans

MiSans is Xiaomi's typeface, designed for clarity, readability and a unified visual style across languages and writing systems.

This community plugin brings **MiSans Regular and Bold** to the SiYuan interface and editor, giving everyday notes, reading and writing a consistent typographic experience.

[![MiSans type specimen](assets/home-grd-1.svg)](assets/home-grd-1.png)

## MiSans Global

Based on the official MiSans introduction, MiSans Global is a multilingual typeface project led by Xiaomi in collaboration with Monotype and Hanyi. The family covers more than 20 writing systems, supports over 600 languages, and includes more than 100,000 characters. Designed as Xiaomi HyperOS's default typeface, it aims to deliver a clear, human-centric and visually consistent multilingual experience.

| Languages | Characters | Writing systems |
| :---: | :---: | :---: |
| **600+** | **100,000+** | **20+** |

These figures describe the complete MiSans Global family. This plugin bundles MiSans Regular and Bold, rather than the entire Global collection.

[![MiSans typography](assets/misans-preview.svg)](preview.png)

## All fonts are variable. No exceptions.

The official MiSans family offers variable fonts and formats including VF, OTF, TTF, WOFF and WOFF2, bringing a consistent design to different languages, weights and layouts. This plugin uses Regular and Bold WOFF files.

[![MiSans design details](assets/home-grd-3.svg)](assets/home-grd-3.png)
